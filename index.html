STAGE 01 PIPELINE & TOKENIZATION

The Source-Line Pipeline

The whole journey is one concept repeated: turn raw text into integers, predict the next token with causal masking, then refine data and loss objectives through SFT, DPO, and GRPO until the model converges on chat. Each stage transforms either the data distribution or the loss function — the underlying Transformer weights and topology remain strictly identical.

Stage Progression

From The Pile to Aligned Chat

Every stage in this repository is implemented in pure PyTorch — no external wrappers like Hugging Face transformers, trl, or peft. The repo's central claim is that the entire LLM lifecycle can be expressed as a single linear substitution τ.

τ : text → tokens → Transformer → CE → base → SFT → {PPO, DPO} → GRPO → chat

Substitution is the rigorous move: any library that wraps these primitives computes the same matrix multiplications underneath. What changes between stages is what the loss sees, never how the model parameterises it.

Why it matters

Notice how each downstream stage changes only the data distribution or the loss formulation, while the underlying Transformer backbone weights and topology remain strictly identical. This is the architectural invariant that makes from-scratch a meaningful claim rather than a marketing one.

    Byte-Pair Tokenizer (BPE) Splitter

    The repo uses tiktoken r50k_base (50 257 tokens, padded to 50 304 for GPU tensor-core alignment). This live playground splits text using GPT-2 regex rules and hashes pieces into simulated IDs.

    How BPE Works

    1. 01 Split text on GPT-2 regex: 's|'t|'re|'ve|'m|'ll|'d| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+
    2. 02 Each chunk becomes a sequence of UTF-8 bytes.
    3. 03 Merge the most frequent adjacent byte-pair repeatedly until vocabulary is full.
    4. 04 Final merged sequences are the tokens — stored as integer IDs.
    STAGE 02 ARCHITECTURE & PARAMETERS

    Transformer Anatomy & Parameter Math

    A clean decoder-only causal Transformer written in raw PyTorch. Inspect the exact closed-form parameter formula, test custom configurations from 13M to 3B+, view the five modular source files, visualise how parameters distribute across components, and budget GPU VRAM requirements.

    Closed-Form Parameter Math

    Analytical Parameter Counting

    Write the model as token and positional embeddings, plus N identical transformer blocks split into Multi-Head Attention and MLP sub-layers. Summing every weight tensor yields a single closed-form formula for total parameters:

    τ(d, N, T, V) = Vd + Td + N(12d² + 10d) + 2d + Vd + V

    Where d = embedding dimension, N = layer blocks, T = context length (256–2048), and V = vocabulary size (50 304). Untied LM projection head.

    The formula decomposes cleanly: Vd for token embeddings, Td for positional embeddings, N(12d² + 10d) for the N transformer blocks (each containing QKV projections, output projection, two MLP layers, and three LayerNorms), 2d for the final LayerNorm, and Vd + V for the untied LM head with bias.

    Did you know?

    In standard causal LLMs, the feedforward MLP uses an intermediate expansion of 4× embedding dimension (4d), accounting for ~66% of total block parameters. This is why most "shrinking" research targets the MLP — replacing it with SwiGLU, MoE, or low-rank adapters — while attention remains untouched.

          STAGE 03
          PRETRAINING & GENERATION
        
      
        
      Next-Token Cross-Entropy Loss & Inference
      
        
      
          Every epoch of pretraining optimises the exact same objective: compute cross-entropy on
          next-token predictions, calculate backward gradients, and descend. Scrub the 77M training
          trajectory on a real SVG line chart and inspect actual model generations across checkpoints.
        
      
      
      

      
      
        
      
          
      The Core Pretraining Objective 
      
          
      Causal Language Modelling Descent
      
          
      
            During pretraining, tokens are processed autoregressively. Each position attends only to
            preceding tokens via the lower-triangular causal mask. The model predicts a probability
            distribution over all 50 304 vocabulary tokens:
          
      
          
      
            L = −(1/T) Σt=1..T log p(yt+1 | x≤t)
          
      
          
      
            Equivalently, in PyTorch:
            F.cross_entropy(logits, targets, ignore_index=−1).
            The ignore index masks prompt tokens during SFT, but in pretraining every position contributes.
          
      
          
      
            In the 77 million parameter training run on The Pile, loss drops rapidly from initial random
            entropy (≈ ln 50304 = 10.83) down to
            3.73 train (3.76 validation) over 2 000 steps —
            a reduction of more than 7 nats per token.

            Training Insight
            
      
              Cross-entropy loss of ~3.7 corresponds to a perplexity of ~42 on diverse internet text —
              enough for the model to learn grammar, spelling, facts, and code syntax from scratch.
              Below ~3.5 the model starts to memorise the training set; below ~2.5 it has overfit
              unless data was scaled proportionally (Chinchilla: 20 tokens per parameter).

          STAGE 04
          POST-TRAINING ALIGNMENT
        
      
        
      Turning a Base Model into an Assistant
      
        
      
          After pretraining, the neural weights are frozen or fine-tuned with new objectives.
          Discover five classic and frontier post-training methods implemented in pure PyTorch on the
          exact same transformer backbone. Each method changes the loss function; none changes the architecture.
        
      
      
      

      
      
        
      
          
      
            
      
              Supervised
              
      Stage 1
      
            
      
            
      SFT: Supervised Fine-Tuning
      
            
      ce = (CE(logits, y) * mask).sum() / mask.sum()
      
            
      Instruction-answer pairs (Alpaca, Dolly). Loss masks prompt tokens so gradients backpropagate solely through assistant responses. Cheapest, most stable, but teaches imitation rather than preference.
      
            
        
              
      • Data10K–100K pairs
        • 
              
      • Cost1× train pass
        • 
              
      • StabilityHigh
        • 
            
      
          
      

          
      
            
      
              Reward Scoring
              
      Stage 2
      
            
      
            
      RM: Reward Modeling
      
            
      L = −log σ(r(chosen) − r(rejected))
      
            
      Bradley-Terry ranking on chosen/rejected preference completions. Replaces LM head with a scalar linear layer to score candidate completions. Required precursor for PPO; bypassed entirely by DPO.
      
            
        
              
      • Data20K–200K prefs
        • 
              
      • Cost1× train pass
        • 
              
      • StabilityMedium
        • 
            
      
          
      

          
      
            
      
              Direct RL
              
      Stage 3
      
            
      
            
      DPO / ORPO / KTO
      
            
      −log σ(β (π log-ratio − π_ref log-ratio))
      
            
      Implicit reward formulation directly optimises policy on preference pairs without separate reward model training or unstable online rollouts. DPO is the workhorse of modern alignment.
      
            
        
              
      • Data5K–50K prefs
        • 
              
      • Cost1× train pass
        • 
              
      • StabilityHigh
        • 
            
      
          
      

          
      
            
      
              Actor-Critic
              
      Stage 4
      
            
      
            
      PPO: Proximal Policy RL
      
            
      −min(ratio · A, clip(ratio, 1±ε) · A)
      
            
      Classic RLHF. Trains actor policy and critic value network with Generalised Advantage Estimation. Powerful but notoriously unstable; requires four models in memory (actor, critic, ref, RM).
      
            
        
              
      • DataOnline rollouts
        • 
              
      • Cost4× memory
        • 
              
      • StabilityLow
        • 
            
      
          
      

          
      
            
      
              Reasoning RL
              
      Stage 5
      
            
      
            
      GRPO: Group Relative RL
      
            
      Ai = (ri − mean(G)) / (std(G) + ε)
      
            
      DeepSeekMath/R1-style alignment. Samples groups of candidate answers per prompt, normalises relative advantage, and drops the critic network entirely. The current state-of-the-art for verifiable reasoning tasks.
      
            
        
              
      • DataVerifiable tasks
        • 
              
      • Cost3× memory
        • 
              
      • StabilityMedium
        •

          STAGE 06
          THEORY & PHILOSOPHY
        
        
        
        The Mathematics & Meaning of τ
        
        
        
          Why training from scratch is about understanding the mathematical invariance of the
          architecture, free from opaque abstraction layers or commercial lock-in.
        
        
      
        

      
        
        
        
          
        Form Over Product 
        
          
        Fit, Not Forced
        
          
        
            A substitution test proves that the core arithmetic does not depend on marketing buzzwords.
            Replace the code with any external library wrapper, and the matrix multiplications compute
            identically. The wrapper changes the engineer's typing; it does not change the gradient.
          
        
          
        
            Yet "from scratch" carries enduring educational significance: one clean architecture,
            built of transparent files, trained on open data, and aligned through loss functions anyone
            can read and inspect. The from-scratch path is not cheaper or faster — it is the only path
            along which understanding is provable.
          
        
          
        
            The Core Tenet
            
        
              Mastery comes from writing every projection, normalisation, attention mask, and reward
              function yourself before delegating to automation. The five PyTorch files in
              src/models/ are deliberately shorter than this
              web page.
            
        
          
        
        
        

        
        
          
        
            
        
              Formal Invariant
              
        The τ System Definition
        
            
        
          
        
          
        
            τ = (MLP, Head, Blockᴺ, CE, SFT → {DPO, PPO, GRPO})
          
        
          
        
            From-scratch, in this reading, names τ. Existence as a commercial hosted service is not
            the goal of this project; understanding the immutable form is.
          
        

          
        
            
        
              
        PROVED
        
              
        T1–T9, closed-form parameter math, CE barrier, unique sink at chat
        
            
        
            
        
              
        STIPULATED
        
              
        r50k_base tokenizer, ReLU activations, untied LM head, pre-LayerNorm
        
            
        
            
        
              
        EMPIRICAL
        
              
        13M / 77M / 406M / 3B scaling runs, GSM8K reward table, RM accuracy 0.574
        
            
        
            
        
              
        EXCLUDED
        
              
        Black-box library wrappers (transformers, trl, peft)
