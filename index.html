Training an LLM from scratch

Code proves a path, not a product. Here the path is occupied: one architecture, a first loss, a source-line of stages, and a unique sink at chat. From-scratch names that path — fitted, not forced.

The operator

The source-line

The whole journey is one idea repeated: turn text into numbers, predict the next token, then keep changing the data and the loss until the model does what we want. This repo occupies that line from The Pile to chat, in plain PyTorch.

τ : text → tokens → Transformer → CE → base → SFT → {PPO, DPO} → GRPO → chat

FN · eleven seats

    Tokenize

    Write n as pieces

    The repo uses tiktoken r50k_base (50 257 tokens, padded to 50 304). This box splits on the GPT-2 regex and hashes each piece so you can see the cut.

    The architecture

    Analeza, for nets

    τ is the kucwenga map of this repo: write a model as (embed × 1), split every block down to MLP and Head, then sum every Linear the splits produce. For n_embed = d the lemma gives a single formula, independent of split order.

    τ(d, N, T, V) = Vd + Td + N(12d² + 10d) + 2d + Vd + V

    Vocab V is 50 304. Untied lm_head. Attention keys have no bias; MLP and projections do. Reported 13M / 77M / 406M counts come from the README; custom uses the formula above.

    Evaluate τ

    d must be divisible by n_head. Head size is d / n_head.

    Post-training
    
        
    Turning a base into an assistant
    
        
    
          After the sink of pretraining, the data changes and the loss changes. The net does not.
          Five methods, all handwritten, all on the same small Transformer.
        
    

        
    
          
    
            
    SFT
    
            
    Supervised fine-tune
    
            
    ce = CE(logits, y) * mask; return ce.sum() / mask.sum()
    
            
    Instruction data (Alpaca, Dolly, GSM8K). Train only on assistant tokens. The base model learns to answer instead of to continue the internet.
    
          
    
          
    
            
    RM
    
            
    Reward model
    
            
    −log σ(r(chosen) − r(rejected))
    
            
    Bradley-Terry on preference pairs. Test accuracy in the README: 0.574 on 7 974 pairs. Weak, and enough to point PPO.
    
          
    
          
    
            
    DPO
    
            
    DPO / ORPO / KTO
    
            
    −log σ(β (π log-ratio − π_ref log-ratio))
    
            
    Preference without sampling from a reward model. ORPO drops the reference. KTO takes unpaired thumbs.
    
          
    
          
    
            
    PPO
    
            
    PPO
    
            
    −min(ratio A, clip(ratio) A) with GAE
    
            
    Classic RLHF. Value head on the same backbone. Reward from the RM or from a verifier.
    
          
    
          
    
            
    GRPO
    
            
    GRPO / RLVR
    
            
    A = (r − mean_G) / (std_G + ε)
    
            
    Group of answers, relative advantage, no value head. The sink of the post-training line when the task can be checked.

      Fit, not force
      
          
      The name
      
          
      
            A substitution test shows that T1–T9 do not print the phrase “from scratch.” Replace it
            with any wrapper — Hugging Face transformers, trl, peft — and every sum of the
            handwritten modules still compiles. That test is valid and small. It shows only that
            arithmetic of tensors does not output a title.
          
      
          
      
            It does not show that every title fits τ equally. “From scratch,” in the inherited
            sense, already carries content: one net, built of small files, trained on public data,
            aligned by losses you can read. τ exhibits a single architecture, a first triad of
            stages, and a unique sink for what those stages generate.
          
      
          
      
            This is a semantic argument, not a tenth evaluation of CE. It stands or falls on whether
            MLP, Head, and Block carry the structural role claimed for them. The README should not
            present it as a theorem. It is the name of the path.
          
      
        
      

        
      
          
      
            τ = (MLP, Head, Blockᴺ, CE, SFT → {DPO, PPO, GRPO})
          
      
          
      
            From-scratch, in this reading, names τ. Existence as a hosted billion-parameter service
            is not a line of this map. Existence as form is.
